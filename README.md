# Pratyush Landekar — WebGL & Next.js 3D Portfolio

An interactive, scroll-reactive 3D portfolio application built with **Next.js 14 (App Router)**, **Three.js / WebGL**, **TypeScript**, and **Tailwind CSS**.

## Features

- **Scene 1 (Seashore Horizon)**: 
  - Dynamic 3D sine-wave particle water grid with an exponential density gradient concentrating particles near the horizon.
  - Solid warm-toned circular sun disc with halo corona placed just above the horizon line.
  - Clean, bold typography presenting "Hi, I am Pratyush Landekar".
- **Scroll Transition (Ocean Dive)**:
  - Scroll-reactive camera mechanics that simulate diving beneath the seashore into the oceanic deep abyss.
  - Surface particles shift upward and towards the viewport while atmosphere and fog transition into deep ocean blues.
- **Scene 2 (Bioluminescent Abyss & Repulsion Physics)**:
  - Volumetric submerged floating particles with continuous Brownian motion and buoyancy oscillation.
  - Interactive mouse repulsion kinetics pushing particles away from cursor proximity with spring damping.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run local development server:
   ```bash
   npm run dev
   ```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

4. Build for production:
   ```bash
   npm run build
   ```
